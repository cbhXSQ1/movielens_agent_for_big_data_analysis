## 1. 背景

项目已经进入迭代二和迭代三：

- **迭代一**：MovieLens 1M 数据清洗 + 五维质量评分，结果带版本、可追溯。
- **迭代二**：分类、聚类、降维等机器学习任务；同一份清洗结果上要对比不同算法/参数，模型有 `model_id`、指标、产物、版本。
- **迭代三**：电影知识图谱；从实体出发沿关系探索，需要回到某个实体换一条路径继续。

重构版前端 `ml-reconstruction/frontend` 已经具备：

- 4 个左栏功能面板：对话列表 / 对话树 / 资源 / 任务进度；
- 对话树浮窗：泳道、曲线、缩略、跳回、分支；
- 结果标签、任务详情、资源上传、模型列表；
- 迭代二 ML 结果视图；
- 真实 Agent API、SSE、Pinia store 和测试。

本次新前端的目标是，在 reconstruction 上完成一次**完整的页面级改造**：

> **以 demo3 的三栏布局和渐变视觉为主，以 reconstruction 现有功能与数据为底座，实现一个聊天优先、结果可展开、实验可分支的数据分析工作台。**

本次一次性交付当前原型里的全部页面与交互，不做“只换壳、功能后补”的分阶段版本。

## 2. 目标与非目标

### 2.1 目标

1. 三栏布局：左栏功能面板、中栏对话/结果工作区、右栏只读上下文摘要。
2. 聊天优先：打开页面默认是对话，结果通过标签展开。
3. 保留 reconstruction 的 4 个左栏功能面板，不把左栏退化成单一对话列表。
4. 对话树必须是「看得出是树、也能跳」：泳道、连线、当前节点、缩略、跳回、在此继续。
5. 结果呈现兼顾「对话内摘要」与「完整结果标签」。
6. 视觉采用 demo3 的色板、渐变、圆角、阴影和 14.5px 密度。
7. 任务状态、失败信息、版本、T1/T2 都可见，但不挤占主视觉。
8. 保留数据诚实规则：不编造、隔离 ≠ 修复、成功前不显示结果。
9. **接真实数据**：所有任务、版本、产物、模型、树节点、资源上传、方案 CRUD、设置、知识图谱交互都来自 reconstruction 现有 store/API/SSE，不使用静态占位数字。
10. **一次性交付完整页面**：当前原型里的左栏 4 面板、树浮窗、结果标签、右栏、输入区、设置等全部实现。
11. **结果改为结果标签**：现有结果视图不再作为顶部一级导航，统一通过中栏标签打开。
12. **树必须可分支**：按 reconstruction 已建好的 tree API/store 实现真正的 `branchFrom`，不降级为只读树。

### 2.2 非目标（v1 不做）

- 暗色主题（下一版再做）。
- 重写后端算法或数据契约。
- 用静态数据冒充真实数据。
- 让 `new-frontend-demo.html` 这个静态原型本身接真实接口；真实数据在 reconstruction Vue 实现中接入。
- 移动端完整功能对齐（只做可用性降级）。
- 多用户/权限/协作。
- 对话树的分支合并、diff、导出（可作为后续迭代）。
- 新建一套独立于 reconstruction 的 Agent/API。

## 3. 用户与核心场景

### 3.1 用户

- 数据分析师：发起清洗、评分、ML 训练、图谱探索。
- 课程评审/组长：快速看到任务状态、结果、版本、质量口径。
- 开发者：通过结果标签和错误信息定位问题。

### 3.2 核心场景

1. **跑清洗与评分**：输入自然语言 → Agent 调用工具 → 中栏出现工具卡片和五维摘要 → 点开完整结果标签。
2. **对比 ML 实验**：在同一个清洗节点上分叉训练随机森林 / K-Means / PCA → 对话树保留旧支 → 对比指标。
3. **图谱探索**：从电影实体出发 → 沿类型/用户群/评分关系继续 → 回到上一步换一条关系。
4. **查看任务**：左栏任务进度查看双编号、阶段、进度、结果六块、版本、T1/T2。
5. **失败诊断**：顶栏出现紧凑状态标签 → 悬停看完整错误（仅截断时）→ 点击打开任务进度。
6. **资源管理**：左栏资源上传原始数据/方案，查看已发布版本、产出文件、模型。

### 6.2 渐变

```css
--grad: linear-gradient(94deg, #3D7EF2 0%, #8B5CF0 52%, #EE7E74 108%);
```

渐变只用于：

- 品牌 ML 块；
- 发送键；
- 任务进度填充；
- 当前标签下划线；
- 当前左栏图标竖条；
- 综合分大数字；
- 五维彩条的「提升」段；
- 树当前节点。

**不用于**普通按钮、表格文字、正文。白字只放在渐变中段/深色端。

### 6.3 字体与密度

- 正文 14.5px，行高 1.7；
- 表格 11.5–12.5px；
- 标签 10.5–11.5px；
- 标题 14–22px；
- 圆角：卡片 18px、控件 13px、小控件 8–9px；
- 阴影：`0 1px 2px rgba(29,30,34,.03), 0 6px 24px rgba(29,30,34,.05)`。

### 6.4 按钮层级

| 层级 | 样式 | 用途 |
|---|---|---|
| 渐变主按钮 | `var(--grad)` + 白字 | **只用于发送键、设置里的保存** |
| 虚线按钮 | 透明底 + 虚线边框 | 新建对话 |
| 白底描边 ghost | 白底 + 边框 + 灰色文字 | 大多数操作：新任务、刷新、下载、打开大图、执行工具、复制等 |
| 浅紫 soft | 浅紫底 + 紫字 | 少数关键但有层级的动作：在此继续、在对话树中继续、查看 metrics |
| 纯文字/链接 | 无边框 | 产物链接、结果入口 |

原则：**不要给每个操作都上渐变。** 渐变是品牌和主操作，不是通用按钮。

### 6.5 亮/暗

- v1 只做亮色。
- 暗色变量可预留，但不做切换按钮。

## 7. 组件与交互需求

### 7.1 左栏品牌与收起

- 品牌块位于左栏顶部，高 60px，与中央顶栏、右栏头部对齐。
- 内容：34px ML 渐变块 + `MovieLens Agent` + `迭代二 · 数据治理与分析`。
- 点击 ML Logo 切换收起/展开。
- 左栏底部箭头也切换收起/展开。
- 展开状态箭头朝左；收起状态箭头旋转 180° 朝右。
- 收起后左栏宽 64px：品牌文字隐藏，只留 ML Logo；面板隐藏；图标条保留。
- 点击图标时如果左栏是收起的，先展开再切换面板。
- 按钮 `title` / `aria-label` 随状态更新为「收起左栏 / 展开左栏」。

### 7.2 中央顶栏

顺序：

```text
当前对话标题   数据版本 v3   [状态标签]        后端已连接 · 8765  [右栏图标] [设置]
```

- 标题过长时省略，`title` 显示全文。
- 数据版本胶囊始终显示（≤760px 可隐藏）。
- 状态标签见 7.3。
- 后端连接状态：绿色圆点 + 文案；≤760px 隐藏。
- 右栏开关：纯图标按钮，`title` 随状态变为「收起右栏 / 展开右栏」。
- 设置：图标按钮，打开设置弹窗。

### 7.3 顶栏任务状态标签

**不再使用横跨中栏的横幅。**

- 有任务时显示为类似「数据版本 v3」的小胶囊；无任务时隐藏。
- 运行中、成功、失败都显示；排队中如已有任务记录也可显示。
- 文案先省略：

| 状态 | 标签文案 | 悬停完整文案 |
|---|---|---|
| 运行中 | `运行中 · 评分表清洗 4/9` | `Hadoop 集群 · 全量运行中 · 评分表清洗 4/9 · 本版不支持取消` |
| 成功 | `已完成 · 9/9` | `全量 · Hadoop 集群执行 · 9/9 阶段成功 · 结果已发布到 HDFS` |
| 失败 | `失败 · 用户表清洗 · 后端启动 Hadoop 失败` | `任务在「用户表清洗」阶段失败 · 后端启动 Hadoop 失败 · 错误 ID 20261017-2210-d7e8` |

- 标签最大宽度：170px（≤760px 为 140px）。
- 文本超出时显示 `…`。
- **只有文本被截断时才设置 `title`**；未截断不显示悬停提示。
- 点击标签打开左栏「任务进度」面板。
- 状态色：运行中黄色，成功绿色，失败红色。

### 7.4 左栏：对话列表

- 搜索框。
- 「＋ 新建」使用虚线按钮。
- 每条对话：标题、任务号/状态、最近时间。
- 当前对话高亮（浅紫底 + 渐变左竖条）。
- 悬停出现删除。
- 点击切换对话，中央顶栏标题同步更新。
- 空态：「还没有对话」。

### 7.5 左栏：对话树

- 面板内是小型 Git 图缩略，不是线性列表。
- 显示当前分支路径、旧支数量。
- 「打开大图」使用 ghost 按钮。
- 完整树在浮窗（见 7.10）。

### 7.6 左栏：资源

五个分段：

1. 原始数据：`ratings.dat` / `users.dat` / `movies.dat`，上传 `.dat` / `.zip`。
2. 已发布：版本、锁、哈希、路径、样本标记。
3. 方案：`cleaning_rules.v1.json`、`scoring_scheme.v1.json`，上传 `.json`、查看、删除。
4. 产出：`report.md`、`metrics.json`、`quarantine_sample.jsonl`、`published_manifest.json`，预览/下载。
5. 模型：迭代二模型列表，`model_id`、类型、算法、指标、下载。

> 资源面板是完整功能入口，不能只用右栏摘要替代。上传、查看、删除、下载全部走真实 API；空态/加载/错误态真实展示。

### 7.7 左栏：任务进度

- 任务卡列表：
  - 双编号：Agent 编号 + Hadoop 编号（卡片上显示 Agent 编号，详情里两者都给）；
  - 名称、状态、阶段、百分比、用时、进度条；
  - **所有任务卡严格等宽（原型四张）**：`display:block; width:100%; text-align:left;`。
- 任务详情：
  - 双编号、状态、阶段、用时、数据版本；
  - 结果按钮 2 列等宽网格：五维评分 / 评估报告 / metrics.json / 依据与局限 / 模型结果（第 5 个跨两列）；
  - 结果六块说明：五维评分 / 数据量 / 隔离样例 / 报告 / 依据与局限 / 任务状态。
- 点击任务卡切换详情；点击结果按钮打开中栏对应标签。

### 7.8 中栏：标签与对话

#### 标签

- 默认只有「对话」。
- 结果标签固定为当前原型的 7 个：对话、五维评分、评估报告.md、metrics.json、方案依据、迭代二模型、知识图谱。
- 不再保留「总览 / 数据清洗 / 证据」作为独立一级标签，除非后续单独提出。
- 每个结果标签可关闭；关闭只关视图，不删产物。
- 全部标签关闭后回到对话。

#### 对话

- 用户气泡靠右，助手内容靠左。
- 助手消息支持：
  - 文字 + 打字光标；
  - 工具调用 `<details>` 卡片（工具名、参数、结果）；
  - 结果摘要卡；
  - 产物链接。
- 结果摘要卡包含：
  - 综合分：`95.07 → 99.95`，大数字用渐变文字；
  - 五维彩条（见 7.9）；
  - 数据量变化小表；
  - 「隔离 ≠ 修复」提示；
  - 「打开完整五维视图」「查看评估报告」。
- 工具调用默认折叠，最近一次可展开。

#### 输入区

结构必须按 demo3：

```text
[LLM 主控 | 离线直调]  [思考档位 高]
[快捷提问 chip] [chip] [chip] [chip]
┌──────────────────────────────────────────────┐
│ textarea                              [发送] │
└──────────────────────────────────────────────┘
Ctrl + Enter 发送 · 结果来自真实 Agent
```

- 模式切换、思考档位在输入卡片**外面**。
- 输入卡片内只有 textarea + 渐变发送键。
- 思考档位是胶囊 + 弹出层（低/中/高），默认高。
- 离线直调时：思考胶囊变灰不可点，发送键隐藏，卡片内换成工具表单。
- 快捷提问 chips 在输入卡片上方。

### 7.9 五维彩条

**要求：看得出清洗前是多少、提升了多少。**

- 每行：维度名 + 彩条 + 数值 + 增量。
- 彩条是两段式：
  - **清洗前**：该维度原来的实色；
  - **提升**：接在后面的品牌渐变段；
  - 两段之间用 1px 白色分隔；
  - 轨道剩余部分用浅灰。
- 宽度按真实值计算：
  - 准确性：97.71% + 2.08%
  - 完整性：98.82% + 1.17%
  - 唯一性：90.90% + 9.10%
  - 时效性：98.22% + 1.78%
  - 一致性：89.65% + 10.35%
- 维度原色：
  - 准确性：蓝
  - 完整性：紫
  - 唯一性：绿
  - 时效性：蓝
  - 一致性：粉
- 图例：`清洗前`（多色小条）/ `提升`（品牌渐变小条）。
- 彩条 `title` 显示完整数值，例如 `97.71 → 99.79（+2.08）`。
- 中栏「五维评分」完整视图使用同一套分段逻辑。

### 7.10 对话树浮窗

- 入口：左栏「对话树」→「打开大图」；知识图谱「在对话树中继续」；对话内「打开对话树」。
- 画布：网格底，横纵滚动。
- 节点 = 一个回合（提问 + 回复），不是一条消息。
- 布局：同泳道竖线，跨泳道贝塞尔曲线；旧支淡显但可点。
- 当前节点：渐变圆点 + 当前标签。
- 悬停/点击：缩略卡显示该回合的提问、回复。
- 「跳回此节点」：切换当前节点。
- 「在此继续」：从该节点新开一支，旧支保留。
- 顶部显示当前节点编号、分支数；支持刷新、关闭、Esc。
- 左侧/右侧说明「为什么是树」：迭代二实验分叉、迭代三图谱路径。

### 7.11 右栏：只读上下文

- 宽 320px，全高，头部 60px 与左栏品牌/中央顶栏对齐。
- 内容：
  1. **当前任务**：任务号、状态、名称、进度条、阶段、用时；
  2. **版本与时间边界**：数据版本、清洗规则、评分方案、T1、T2；
  3. **最近产物（全局）**：不限制当前任务，按最近生成/打开时间排序，列出五维评分 / 评估报告 / metrics.json / 迭代二模型等，点击打开标签；
  4. **结果入口**：五维评分 / 评估报告 / 指标 JSON / 方案依据 / 迭代二模型 / 知识图谱。
- 右栏**不提供**上传、删除、模型管理、方案编辑。
- 收起方式：
  - 中央顶栏右栏图标；
  - 右栏头部箭头；
  - 收起后右缘 24px「上下文」竖条。
- 收起状态记 `localStorage`。
- ≤1360px：右栏变浮层，默认隐藏，右缘竖条打开；点击结果入口后自动关闭浮层。
- 右栏所有内容接真实 store：当前任务来自 tasks store，版本/T1/T2 来自 result，最近产物来自 artifacts，结果入口只打开已有标签。
- 「演示状态」切换只存在于原型，生产环境移除，由真实任务状态驱动。
- 无任务/无结果时显示空态，不显示假数字。

### 7.12 结果视图

1. **五维评分**：综合分、五维分段彩条、数据量变化、版本与 T1/T2。
2. **评估报告.md**：Markdown 渲染，复制/下载。
3. **metrics.json**：格式化 JSON，复制/下载。
4. **方案依据**：清洗方案、评分方案、时间边界、版本与可追溯。
5. **迭代二模型**：
   - 分类：AUC/F1/PR-AUC/混淆矩阵/特征重要性/split sizes/leakage；
   - 聚类：k/轮廓系数/Davies-Bouldin/群体 label、size、top genres、behavior；
   - 降维：PCA 解释方差/重构误差/资源/降维前后对比/ARI/NMI；
   - 模型编号 = 任务编号。
6. **知识图谱**：电影/类型/用户群/评分/候选集节点与关系，数据来自真实图谱接口；「在对话树中继续」。

### 7.13 设置

- 启用大模型主控开关。
- API 地址、API Key、模型名。
- 测试连接、保存、关闭。
- 「保存」是唯一保留渐变的主按钮之一。
- 密钥只保存在本机浏览器。

## 8. 状态与数据诚实规则

### 8.1 任务状态

| 状态 | 表现 |
|---|---|
| queued | 排队中；不显示结果 |
| running | 顶栏黄色状态标签；任务卡显示进度；不显示结果数字 |
| succeeded | 顶栏绿色「已完成」状态标签；结果标签可用；右栏显示版本 |
| failed | 顶栏红色状态标签；任务卡失败；错误可查看 |

> 运行中、成功、失败都显示状态标签；无任务时整个标签隐藏。

### 8.2 数据规则

- 任务成功前不显示任何结果数字。
- 失败时给阶段、错误 ID、真实原因，不伪装成功。
- 隔离 ≠ 修复：综合分与数据量变化同屏。
- 本地引擎 / 抽样 / 集群必须有环境徽标。
- 不把 LLM 生成的数字当权威结果；数字只来自 driver。
- 版本不可覆盖；发布冲突要报错，不静默覆盖。

## 9. 与 reconstruction 数据层对接

本次不再新增一套独立后端，直接使用 reconstruction 已建好的 Agent/API、SSE 与 Pinia store。

### 9.1 现有数据来源

| 数据 | 来源 |
|---|---|
| 对话列表 / 消息 / 流式 | `stores/conversations` + 每对话 SSE |
| 对话节点 / 当前分支 / 分支动作 | `stores/tree` + 现有 `branchFrom(tipId)` |
| 任务列表 / 状态 / 进度 / 双编号 | `stores/tasks` + task API |
| 任务结果 / 版本 / T1/T2 | `stores/tasks` 的 result / status |
| 资源：原始数据 / 已发布 / 方案 / 产出 | `stores/resources` + 现有上传/下载 API |
| 模型列表 / 详情 / 下载 | `stores/models` + `stores/resources` |
| 结果标签 / 文件预览 | `stores/centerTabs` + `stores/artifacts` + 现有 ArtifactView |
| 设置 / LLM 连接 | `stores/settings` + `/api/llm/test` |

### 9.2 数据规则

- 所有数字、任务、模型、产物、树节点来自真实 store/API/SSE，不使用静态占位。
- 加载中显示 skeleton / loading；空数据显示空态；接口失败显示错误态，不伪装成功。
- 右栏与左栏共享同一份 store，不建立第二套事实源。
- 树的分支必须走现有后端 `branchFrom`；不允许只在前端伪造节点。
- 如果某个字段/接口确实缺失，先记录为 blocker，不用假数据补齐。

### 9.3 原型与生产差异

- 原型里的「演示状态」切换、静态任务号、静态指标仅用于视觉评审；生产环境移除，由真实任务驱动。
- 原型里的绿/黄/红状态标签保留，但内容来自真实 `status` / `error`。
- 原型里的静态 `report.md` / `metrics.json` 内容改为真实产物接口数据。
