3. 处理了哪些问题

  • 文本编码修复（P1）：48 行；

4. 评价局限

  • 用户属性为自愿填写、未经核验，准确性与完整性不封顶；
  • 分数提升有一部分来自把无法判定的记录移出分母，不等于这些问题被修复；
  • 当前为单机伪分布式部署，未做多机验证；
  • “评分是否真实反映用户偏好”无法从数据本身判定。
隔离 ≠ 修复：隔离 100,830 行、去重 49,510 行、修复 13,503 行，三项独立统计；报告同屏披露数据量变化。
