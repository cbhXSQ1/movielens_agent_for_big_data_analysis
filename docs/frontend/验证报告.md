### 4.1 废弃字段

| 检索 | 命中 | 结论 |
|---|---|---|
| `[Ii]ntent` | **0** | 不依赖 `intent` / `intent_cn` |

## 5. 未达成 / 降级项（如实标注）

以下为**验证边界**，非缺陷；如需更强证据需在真实环境补做：

1. **真实后端端到端未跑**：全部用例以假 SSE 流（`FakeEventSource`）与假后端（stub `fetch` / mock `@/api/*`）驱动，未连真实 Agent 服务。
2. **真实浏览器未测**：无 E2E 工具，组件测试运行在 jsdom（Naive UI 真实挂载）。真实渲染、指针拖拽、滚轮、下载落盘、剪贴板行为仅有单测级别证据（如复制仅断言 `navigator.clipboard.writeText` 被调用）。
3. **对话树「平移」为机制级证据**：以「画布足尺寸 + `overflow:auto` 滚动容器」证明可滚动平移，未模拟真实滑块拖动。
4. **预览/下载为形状级证据**：断言请求构造（`task_id`/`path`、下载 URL）与返回分支，未验证真实文件流。
5. **DoD 文本「六类标签」与实现差一**：实现为 7 类（多「依据」）——依计划 §9 `FI.0` 明确新增第 7 标签，属**计划内演进**，非回归。
6. **构建告警**：`vite build` 提示单 chunk > 500 kB（警告，非错误），不影响产物正确性。
