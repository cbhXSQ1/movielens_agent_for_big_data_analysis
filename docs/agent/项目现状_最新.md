**LLM 可选层的定位（重要，别讲错）**：
- 官方**不要求**也不禁止 → 定位为**可选增强层**，不是必需功能
- 只做两件事：① 帮用户把话理解成调用 ② 把自述句说得更顺
- **不生成清洗规则、不产出任何数字**；数字先换成占位符再交给它，回来过四道校验
- 默认关闭（`AGENT_LLM_SUPPORTED` 不设就是关），**关着时行为与纯规则 100% 一致**
- 实测：英文/中文都能解析，`/api/llm/test` 延迟 882ms，护栏把 help 文本里的数字原样保住
