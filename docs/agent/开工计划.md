## 二、7 个 Agent 工具 ↔ driver 子命令

| Agent 工具 | 调用的命令 | 用途 |
|---|---|---|
| `start_cleaning_task(...)` | `start` | 发起任务，拿到 task_id，立即回用户"任务已提交" |
| `get_task_status(task_id)` | `status` | 展示进度（如"60% ratings_dedupe"） |
| `get_task_result(task_id)` | `result` | 五维对比、数据量变化、隔离统计 |
| `list_schemes()` | `schemes` | 解释"已登记默认方案" |
| `get_samples(task_id, type, table, n)` | `samples` | 回答追问（"给我看看异常记录"） |
| `validate_config(rules, scoring)` | `validate` | 用户自定义配置时先校验 |
| `get_report(task_id, format)` | `report` | 出完整报告 |

调用形式：

```bash
python3 hadoop/driver/run_task.py <subcommand> [options]
```

## 三、硬性约束（接口规范原文）

- stdout 只输出一个 JSON 信封：`{"ok":true,...}` 或 `{"ok":false,"error":{...}}`
- 退出码：`0` 成功 / `2` 参数非法 / `3` 任务失败 / `4` 任务不存在 / `5` 任务未完成 / `6` 版本冲突
- **任务失败或未完成时，`result` 会拒绝返回**（码 3/5）—— 此时 Agent 必须如实说状态与原因
- **不编造**：解释结果必须引用 `result` 里的实际数字与 `limitations`
