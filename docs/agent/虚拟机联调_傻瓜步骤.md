> 每一步都给了可以直接复制的命令。复制 → 粘贴 → 回车。

## 第 0 步：看一眼现在的状态

```bash
jps
echo "HADOOP_HOME=$HADOOP_HOME"
echo "JAVA_HOME=$JAVA_HOME"
```

你现在 `jps` 只有 **5 个**进程，少了 **JobHistoryServer**。
不补的话：作业明明跑成功了，程序却会报"失败"（队长踩过的坑，见 `docs/hadoop/decisions.md` D-013）。
**长作业必踩，短作业看不出来**——所以必须现在补。

## 第 1 步：补 JobHistoryServer（关键，别跳过）

### 1.1 给 mapred-site.xml 加 4 段配置

```bash
sudo python3 - <<'EOF'
p = "/opt/hadoop/etc/hadoop/mapred-site.xml"
s = open(p).read()
add = """  <property><name>mapreduce.jobhistory.address</name><value>localhost:10020</value></property>
  <property><name>mapreduce.jobhistory.webapp.address</name><value>localhost:19888</value></property>
  <property><name>mapreduce.jobhistory.intermediate-done-dir</name><value>/tmp/hadoop/mapreduce/jobhistory/done_intermediate</value></property>
  <property><name>mapreduce.jobhistory.done-dir</name><value>/tmp/hadoop/mapreduce/jobhistory/done</value></property>
"""
if "jobhistory.address" in s:
    print("已经加过了，跳过")
else:
    open(p, "w").write(s.replace("</configuration>", add + "</configuration>"))
    print("配置已写入")
EOF
```

### 1.2 重启 YARN 并启动历史服务器

```bash
stop-yarn.sh
start-yarn.sh
mapred --daemon start historyserver
jps
```

✅ **这一步成功的标志：`jps` 变成 6 个进程**，多出来的是 `JobHistoryServer`。
如果还是 5 个，把 `mapred --daemon start historyserver` 的输出发给我。


## 第 4.5 步：冒烟测试报 `Job not successful` 怎么办

现象：`=== [3/5] 提交 Streaming 作业 ===` 之后出现 `Failing the application.`
`ERROR streaming.StreamJob: Job not successful!`

**原因**：`/opt/hadoop` 自带配置缺了 YARN 内存参数（队长记录的 **D-014**），
容器申请不到内存就直接挂掉。补上即可，不是你的操作问题。

### 看真凶（可选，想知道具体原因就跑）

```bash
yarn logs -applicationId application_1790313773447_0001 2>/dev/null | grep -iE "error|exception|killed|memory|Failing" | tail -25
```

（applicationId 换成你屏幕上实际那个）

### 补配置（幂等，已有项不会重复添加）

```bash
sudo python3 - <<'EOF'
yarn = "/opt/hadoop/etc/hadoop/yarn-site.xml"
mr   = "/opt/hadoop/etc/hadoop/mapred-site.xml"

yarn_props = [
 ("yarn.nodemanager.resource.memory-mb","4096"),
 ("yarn.scheduler.minimum-allocation-mb","512"),
 ("yarn.scheduler.maximum-allocation-mb","4096"),
 ("yarn.nodemanager.resource.cpu-vcores","4"),
 ("yarn.nodemanager.vmem-check-enabled","false"),
]
mr_props = [
 ("yarn.app.mapreduce.am.env","HADOOP_MAPRED_HOME=/opt/hadoop"),
 ("mapreduce.map.env","HADOOP_MAPRED_HOME=/opt/hadoop"),
 ("mapreduce.reduce.env","HADOOP_MAPRED_HOME=/opt/hadoop"),
 ("mapreduce.application.classpath","/opt/hadoop/share/hadoop/mapreduce/*:/opt/hadoop/share/hadoop/mapreduce/lib/*"),
 ("mapreduce.map.memory.mb","1024"),
 ("mapreduce.reduce.memory.mb","1024"),
 ("mapreduce.map.java.opts","-Xmx768m"),
 ("mapreduce.reduce.java.opts","-Xmx768m"),
]

def patch(path, props):
    s = open(path).read()
    add = ""
    for n, v in props:
        if "<name>%s</name>" % n in s:
            continue
        add += "  <property><name>%s</name><value>%s</value></property>\n" % (n, v)
    if add:
        open(path, "w").write(s.replace("</configuration>", add + "</configuration>"))
        print("已补 %d 项 -> %s" % (add.count("<property>"), path))
    else:
        print("无需修改 -> %s" % path)

patch(yarn, yarn_props)
patch(mr, mr_props)
EOF
```

## 出错了怎么办

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `jps` 不到 6 个 | JobHistoryServer 没起来 | 重跑第 1.2 步，把输出发我 |
| `wget: Connection refused` | 宿主机防火墙没放行 / 服务窗口关了 | 防火墙点允许；服务窗口别关 |
| `STREAMING_JAR 不存在` | jar 文件名不对 | 按 `ls` 的真实名字改 |
| `raw data MISSING` | `ML_RAW_DIR` 写错 | 用 `find ~ -name ratings.dat` 找 |
| 作业跑很久没动静 | 正常，全量约 20~30 分钟 | 等着，别 Ctrl+C |
| `TASK_FAILED` | 真失败了 | 把错误里的 `stage` 和 `message` 发给我 |
