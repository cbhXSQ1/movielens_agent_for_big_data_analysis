## 3. 本次补/加固的测试（明细）

新增文件 `agent/tests/test_tx_verification.py`（11 条），全部用假模型 / 假后端 / 假执行器，
不触网、不碰真实 driver：

- **TX.1（6 条）**：假传输按脚本产出并记录请求；可注入预置故障；多轮脚本用尽后重复最后；
  **可重放**（同脚本两次装配产出逐事件相同 dict）；假工具后端返回并记录、未登记工具给
  `USAGE`；假执行器 `start/complete/vanish` 可控。
- **TX.2（1 条）**：一回合内 `list_tasks → get_task_status → 分片最终回答`，
  断言两步顺序/参数、`message_delta` 逐段且拼接等于 `final`。
- **TX.4（3 条）**：多来源数字全放行 + 负向对照仍拦截；运行期放行且回答**一字未改**。
- **TX.5（1 条）**：分支活动后主支消息/节点内容不变，且**关闭并重开 Runtime**后主支
  仍不含分支文本、新支仍含其祖先上下文。

加固（对已有但断言不足处）：
- 护栏正向断言：从「单来源」扩到「工具标量 + 数组长度 + 用户原话」三来源同屏放行，
  并显式断言护栏**不修改**回答。
- 分支隔离：从「运行时主支未污染」扩到「**持久化后**主支仍未污染」，排除内存假象。
