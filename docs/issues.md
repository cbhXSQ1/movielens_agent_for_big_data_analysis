# 实验问题记录本

**用途：** 实验过程中真实踩到的坑，随手记在这里。
**为什么记：** 作业二要求每个问题写明"判断证据"，来自实验的真实问题比事后编的有说服力，直接引用即可。

**格式：**

```
## [日期] 一句话描述
- 现象：
- 触发条件：
- 影响：
- 怎么发现的：
```

---

## 示例（待替换为真实记录）

## [2026-09-25] 评分作业重跑后结果文件被覆盖，前后对不上
- 现象：第二次跑评分，输出目录里只剩一份结果，无法确认哪份是权威的
- 触发条件：同一任务重复提交，未加任务 ID 区分
- 影响：Agent 展示的分数可能来自旧版本，用户无法察觉
- 怎么发现的：对比两次日志发现输出路径相同
