# 交付前清理清单

> 用途：记录「开发/联调期为了在本机方便而加的东西」，**正式交付前必须删除或还原**。
> 原则：本机测试路径/环境不是交付的一部分；数据理论上只在分布式系统里。

## 必须删除 / 还原

1. **`start_backend.bat` 里对 `ML_RAW_DIR` 的自动探测**
   - 位置：`start_backend.bat` 中两行 `if not defined ML_RAW_DIR if exist "%~dp0..\ml-1m..." set ...`。
   - 为什么加：本机跑**本地引擎**联调时，driver 需要 `ML_RAW_DIR` 指向 `ml-1m` 三表所在目录（宿主机上是 `..\ml-1m\ml-1m`）。
   - 为什么删：数据**只在分布式系统里**，本机原始数据位置不固定；把「探测某个相对路径」留在交付脚本里等于把本地假设带进系统。
   - 交付前：删除该两行（以及上面的 TODO 注释块）。需要本地跑时，手动 `set ML_RAW_DIR=...` 即可。

## 交付时一并核对

2. `frontend/node_modules/`、`frontend/dist/`、`.venv/`、`.scratch/`、`agent/var/` 等运行期产物**不应入库**（已被 `.gitignore` 覆盖，交付前 `git status` 再确认）。
3. 仓库内不得出现任何 API Key / 密钥（`config/llm.settings.json` 已 gitignore）。
4. `opencode.json`（子智能体模型配置）在工作区根、**不在仓库内**；如将来纳入仓库需评估是否随交付。
