## 0. 范围与前提

- 迭代二使用迭代一输出的**清洗数据**与**时间边界 T1/T2**，增加三类分析能力：**分类、聚类、降维**。
- 每类**各选两种算法**，且**每种算法封装为 Agent 可独立调用的工具**。
- 计算放**虚拟机端侧**（数据在发布区）；宿主机 Agent 通过**能力服务**调用。
- **数据如何与 Hadoop 结合（读 HDFS / 落地文件、调度、资源）由虚拟机端侧决定**；本文件规定：算法路径与选择理由、输入口径、产物与版本、对外契约、前端呈现。

## 1. 数据边界（三类任务共同遵守）

- **数据源**：迭代一发布区 `ml1m-clean-v1`（`ratings` / `users` / `movies`），携带数据版本与哈希。
- **时间划分**：训练 ≤ T1、验证 (T1, T2]、测试 > T2（沿用迭代一确定的 T1/T2）。
- **防时间泄漏（硬约束）**：所有历史统计特征只用**预测时点之前**的数据（点对点构建），绝不用验证/测试期信息构造训练输入。
- **不用占位/示例/推测数据**；失败要如实返回失败环节与原因。

## 2. 分类

- **任务**：预测"某用户对某电影的一次评分是否 ≥ 4 分"（≥4 为正类）。
- **两种算法**：**朴素贝叶斯 + 树集成**。
  - 树集成默认 **随机森林（RandomForest）**（scikit-learn 内置、零额外依赖）；**备选 XGBoost**（性能通常更强，需安装 `xgboost`；端侧能装则优先 XGBoost，否则用随机森林）。二者都落在课程 PPT 的"决策树/集成学习"范畴，与朴素贝叶斯共同满足"至少含朴素贝叶斯或决策树之一"。
- **算法路径与选择理由（要点）**：
  - 朴素贝叶斯：概率生成式、训练快、对类别特征友好、可解释（各特征对后验的贡献）；局限是特征条件独立假设较强、对特征相关与连续特征分布敏感。
  - 树集成：非线性、能自动捕捉特征交互、给出**特征重要性**、通常指标更好；代价是需调参（树数、深度、学习率）、可解释性弱于单棵树。
  - 两者决策机制差异大（贝叶斯 vs 划分/提升），对比有信息量，正合作业四"候选差异以便比较"的要求。
- **特征（4–6 个，至少含 1 类别 + 1 数值）**：
  - 类别：`Gender`、`Age`、`Occupation`（OneHot / Ordinal）、`Genres`（Multi-hot）。
  - 数值：电影历史均分、电影热度（截止时点前被评次数）、用户历史均分、用户活跃度（评分次数）。
  - 编码器与模型一起落盘；未知类别用 `handle_unknown="ignore"`。
- **主指标**：**F1 与 AUC（ROC-AUC）**（并给 Precision/Recall、混淆矩阵）；因正类不平衡，**同时报告 PR-AUC** 作补充。
- **阈值**：默认 0.5，报告阈值变化对误报/漏报的影响。
- 两种算法**同数据范围、同口径**。

## 3. 聚类

- **输入：用户偏好画像** = 18 个电影类型的偏好占比 + 4 个行为统计（活跃度、均分、评分波动、最近活跃）；只用训练窗口（≤T1）的评分构建；行内归一化 + 连续维标准化。
- **两种算法**：**K-Means + 凝聚层次聚类（Ward）**；K-Means 固定随机种子 + 多次初始化取最优（结果确定、可复现）。
- **k 的选择**：轮廓系数 / 肘部法选定，两种算法使用**同一个 k**。
- **可解释群体画像（重点）**：每个群体给出——规模、相对全局**偏离最大的 2–3 个类型**、行为均值、**自动生成的中文标签**（如"动作/科幻偏好 · 高活跃 · 评分偏严"）。标签由数据驱动生成、可复现。
- **指标**：轮廓系数、Davies-Bouldin、群体规模分布。
- **产物**：群体模型、每用户群标签、群体画像（含标签）。

## 4. 降维

- **输入**：同一份用户画像矩阵。
- **两种算法**：**PCA + NMF**；NMF 的**非负处理采用整体平移**（MinMax 平移到 [0,1]），保留全部维度、与 PCA 在同一矩阵上公平对比。
- **对比实验协议**：固定其它变量，只变"降维开/关"与"哪种降维"。
  1. **降维前后聚类一致性**：把 (a) 全维画像 与 (b) 降维后的表示，分别喂给**同一个聚类算法**，用 **ARI / NMI / 轮廓系数**比较分组是否一致。
  2. **信息保留**：PCA 的**解释方差比**与**重构误差**；NMF 的**重构误差**。
  3. **资源开销**：降维 + 下游聚类的**时间与内存**。
- **产物**：降维模型、用户坐标、指标对比表。

## 5. 能力与工具（对外契约，供端侧实现）

- **每个算法一个工具**（长任务，异步受理 + 查询/等待）：
  - `train_classifier_naive_bayes`
  - `train_classifier_tree`（随机森林；若端侧选 XGBoost 则实现为 `train_classifier_xgboost`，二者择一，命名随实现）
  - `cluster_kmeans`
  - `cluster_hierarchical`
  - `reduce_pca`
  - `reduce_nmf`
- **预测工具**：`predict_high_rating(model_id, user_id, movie_id)`——用已存模型对新"用户×电影"事件预测是否高分（分类）。
- **模型/产物查询**：提供"列模型 / 取模型元数据 / 取结果指标"的最小接口（可复用现有"取结果/产物"机制）。
- **信封与错误码**沿用现有能力服务规范（`interface_version`、结构化错误码，加性变更不升版本）。

## 6. 落盘模型与产物（模型文件是什么）

- **模型对象**：sklearn 估计器（朴素贝叶斯、随机森林、KMeans、凝聚层次、PCA、NMF）与其配套的编码/预处理（OneHot/Ordinal/MultiLabelBinarizer/StandardScaler、NMF 平移 MinMax）用 **joblib** 序列化为 `.joblib`；XGBoost 用其原生 `.json`/`.ubj`。
- **元数据 sidecar（JSON）**：模型编号、算法、超参、训练窗口（≤T1）、特征清单与编码器引用、`data_version`、方案版本、**指标（F1/AUC/PR-AUC 等）**、混淆矩阵、时间戳。
- **数据类产物**：每用户群标签（CSV/JSONL）、群体画像（JSON）、降维坐标（CSV/JSONL）。
- **目录与版本**：`var/ml/<模型编号>/`（模型 + 元数据 + 产物）；登记到索引，携带**数据版本 + 算法 + 参数指纹**，供迭代三复用。

## 7. 前端

- 把现在的「预测」占位替换为三块真视图：
  1. 分类指标卡：F1、AUC、（PR-AUC）、混淆矩阵、特征重要性。
  2. 聚类群体画像：每群的中文标签、规模、类型/行为偏离。
  3. 降维对比表 + 散点图：降维前后聚类一致性、信息保留、资源开销；用户坐标散点。

## 附：算法路径选择速览（供作业四与汇报引用）

| 任务 | 算法一 | 算法二 | 选择理由（一句话） |
|---|---|---|---|
| 分类 | 朴素贝叶斯 | 随机森林（备选 XGBoost） | 生成式概率 vs 树集成，机制差异大、兼顾可解释与精度 |
| 聚类 | K-Means | 凝聚层次（Ward） | 质心=可解释群体画像；层次=群体结构/树状图 |
| 降维 | PCA | NMF | 方差最大化（线性）vs 部分式分解（可解释"典型口味"） |
